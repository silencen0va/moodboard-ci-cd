## О проекте

Moodboard - веб-приложение на Python и Flask, выполненное в стиле Pinterest.

Приложение позволяет пользователю:
- искать изображения по ключевым словам;
- получать рекомендации поисковых запросов от AI;
- добавлять изображения в избранное;
- просматривать избранные изображения;
- использовать AI-чат;
- переключать язык интерфейса.

## Используемые технологии

- Python 3.11
- Flask
- HTML / CSS / JavaScript
- OpenAI API
- Unsplash API
- pytest
- Git
- GitHub
- GitHub Actions

## CI/CD

Для автоматизации проверки проекта используется GitHub Actions.

Pipeline запускается автоматически после `push` в ветку `main`.

Основные этапы:

1. Checkout репозитория
2. Установка Python
3. Установка зависимостей
4. Build — проверка синтаксиса Python
5. Test — запуск автоматических тестов с помощью pytest

## Тестирование

В проекте реализованы два автоматических теста:

- `test_home_page` — проверяет доступность главной страницы;
- `test_favorite_route` — проверяет добавление изображения в избранное.

Все тесты автоматически запускаются через GitHub Actions.
